🎓 EduTrack — Learn • Track • Grow
EduTrack is an all-in-one academic management and submission tracking application designed specifically for students to organize their coursework, keep up with assignment deadlines, and manage file submissions effortlessly.

🌟 Project Overview
Navigating multiple courses, project deadlines, and subject activities can quickly become overwhelming. EduTrack simplifies student life by offering a centralized dashboard where users can view enrolled subjects, monitor submission statuses in real time, and upload required assignment files directly from their mobile devices.

✨ Key Features
🔐 Seamless Authentication & User Profile

Quick and secure email or Google login flow.

Personalized user profile displaying full student details (e.g., Jose Miguel Mansilungan), email, academic role, and enrolled course info.

📊 Interactive Expandable Dashboard

Clean sidebar navigation featuring a collapsible Dashboard toggle menu.

Instant access to categorized academic tasks with smooth slide in/out transitions.

📚 Enrolled Subjects Management

Overview cards tailored for core subjects (such as MAD 213, IS DCN 213, CC IM 213, CT-WA 213, and IS-DSA 213).

Real-time submission counters showing completed tasks versus pending requirements for each course.

📝 Submissions & Deadlines Tracker

Dynamic category filters for Activities, Quizzes, and Projects.

Clear status indicators for items marked as Due Today, Due Tomorrow, or Submitted.

Integrated search functionality to easily filter tasks by course code or assignment title.

📎 Integrated File Upload & Submission

Built-in device file picker allowing students to attach documents (.pdf, .docx, .zip, .pkt, etc.) directly to specific project or activity prompts.

Dynamic updates that mark tasks as "Submitted" once the file attachment is confirmed.

🛠️ Tech Stack & Architecture
Language: Kotlin

UI Framework: Android XML Layouts & Material Design Components / Jetpack Compose

Architecture: Activity-based with dynamic view manipulations and animation helpers (expand/collapse height transformations)

Storage: Android SharedPreferences for user session management and local state handling

System Integration: Android ActivityResultContracts Native Storage Access Framework for document picking

🎯 Target Audience
Designed for college and university students (such as Information Technology & Computer Technology majors) seeking a structured tool to manage complex assignment schedules, maintain accountability, and streamline project file uploads on the go.
